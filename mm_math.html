Главный вывод: откуда берётся прибыль

T1 прибыльный (+73.9 SOL) потому что:
→ Органика в итоге создала достаточно покупок ($37k–$67k)
→ С мин.15 команда начала NET_SELL в растущий рынок
→ Дамп: 91 SELL при MC=$67k → забирают всё сразу
→ Снайперы (Wallet_117, 113 и др.) купили при MC=$3k, продали при $67k = +4 SOL каждый
T2 убыточный (−138 SOL) потому что:
→ Органика ПОСТОЯННО продавала больше, чем покупала
→ Команда была вынуждена поглощать продажи каждую минуту
→ NET_SELL режим включился только 2 раза (мин.12 и мин.37)
→ MC никогда не достиг стандартного $69k → меньше прибыли со снайперов
Почему мигрировали при $34.54k а не $69k:

Миграция на pump_swap = стоимость ~20 SOL из пула
Алгоритм считает: tokens_held × current_price ≥ loss + 20 SOL

При T2: потеряно ~138 SOL в торговле. Если ждать $69k — нужно ещё ~100 SOL в покупках поддержки. Лучше зафиксировать убыток на $34.54k, чем потерять ещё 100 SOL.

Триггер выхода = (ожидаемая_органика × оставшееся_время) < текущий_убыток

Математическая модель алгоритма

Переменные состояния (обновляются каждый слот)

net_realized = Σ(sell_sol) − Σ(buy_sol) tokens_held = Σ(buy_tok) − Σ(sell_tok) unrealized = tokens_held × current_price total_pnl = net_realized + unrealized org_flow_1m = Σ(org_buy) − Σ(org_sell) за последние 60 секунд org_flow_5m = rolling sum org_net за 5 мин

Условия переключения режима

IF org_flow_1m > +2 SOL: mode = SELL # органика берёт → продаём ELIF org_flow_1m < -2 SOL: mode = BUY # органика сливает → поглощаем ELIF mc > target_mc × 0.80: mode = SELL # выше 80% цели → тоже продаём ELSE: mode = NEUTRAL # одинаково buy/sell

Условие EXIT (дамп)

exit_condition = ( mc >= target_mc × 0.98 # близко к цели AND org_flow_5m < threshold_low # органика слабеет AND net_realized > migration_cost # покрыли миграцию )
T1: net_realized НЕ превышал +20 SOL до самого дампа. Но tokens_held × $67k было достаточно → total_pnl был положительным. Алгоритм смотрит на TOTAL, не только realized.

Условие EARLY EXIT (T2 сценарий)

early_exit = ( org_flow_5m < −10 SOL # органика сильно продаёт AND total_pnl deteriorating # P&L ухудшается AND time_since_launch > 30 мин # достаточно времени ) → MIGRATE at current_mc (даже ниже target)
T2: organic net = −117 SOL за 40 мин. Алгоритм понял что органика не придёт. Мигрировал при $34.54k чтобы не терять больше.
