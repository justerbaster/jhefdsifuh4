ТЗ по пунктам — настройка таймингов и параметров

Как масштабировать под любой целевой MC

Формула размера сделки:
BUY_size = current_MC × 0.00060 (≈ 0.06% от текущего MC)
SELL_size = current_MC × 0.00110 (≈ 0.11% от текущего MC)

Проверка: при MC=$30k → BUY=$18, SELL=$33 ✓ (совпадает с T2 данными)
Целевой MC для выхода:
T1: выход при MC ≈ $67k (pump.fun стандарт $69k)
T2: выход при MC ≈ $34.5k (половина стандарта — кастомный параметр)
Параметр: EXIT_MC_TARGET — задаётся при запуске бота
Дамп-механизм: при достижении EXIT_MC_TARGET активируется одновременно для всех кошельков. Задержки между кошельками — случайные 0-3 секунды. Все сделки в 1-2 последовательных слотах. MC падает на 60-80% за 30-60 секунд.
